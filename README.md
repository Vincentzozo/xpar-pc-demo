# XPAR PC 软件 · 完全版

面向植物室内种植多合一传感器的 PC 软件界面原型。保留 Windows 仪器软件布局、大数值、光谱、中英切换、记录分析与设备维护页面。

在线预览：https://vincentzozo.github.io/xpar-pc-demo/

默认进入用户模式。工程师入口位于右上角；原型账号为 engineer，接受任意非空密码，刷新后返回用户模式。该入口用于界面评审，尚未实现正式认证。

面向实际设备使用；不提供模拟读数、合成历史或光照滑杆。设备未连接时数值显示“—”，设备操作不可用。目前尚未接入串口/Modbus通信，不能据此声称真机功能已完成。

下载 index.html 后可离线查看。显示偏好与本机配置备份可以操作；测量采集、记录与测量文件导出仍需真实设备通信实现。
